# Windows Application Input

Upload one Windows application source ZIP at a time
into this directory.

## Submission Rules

1. Submit application source code where available.
2. Do not upload passwords, API keys, or private credentials.
3. Do not upload confidential or unauthorised material.
4. Keep the ZIP below the workflow's 200 MB limit.
5. Submit only one ZIP archive per workflow run.

## Processing

The GitHub Actions workflow validates the archive
before extracting its contents.

Submitted code is not intended to be executed
during the initial inspection stage.

Successful inspection results are published as
GitHub Actions artifacts.
