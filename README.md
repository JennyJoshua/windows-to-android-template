# Windows-to-Android Conversion Template

A reusable GitHub template for inspecting, converting, porting,
and rebuilding Windows applications for Android.

The project uses GitHub Actions to automate source inspection,
compatibility analysis, testing, Android builds, and artifact
publication wherever practical.

## Project Status

**Version:** 0.1.0  
**Status:** Initial setup  
**Platform:** GitHub Actions  
**Primary management device:** Android phone

This template is under development. Not all planned automation
features are available yet.

## What This Template Does

The intended workflow is to:

1. Accept Windows application source archives.
2. Validate and safely extract uploaded projects.
3. Identify programming languages and frameworks.
4. Inspect dependencies and Windows-specific functionality.
5. Assess compatibility with Android.
6. Recommend an appropriate conversion strategy.
7. Prepare a conversion plan for approval
